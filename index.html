    Manual pages 10–15

    Getting started

    Patch an input to an output-processing algorithm, then add generators, utilities or effects as separate algorithm slots. A preset is the complete ordered algorithm list, all parameter values, mappings, Performance Page assignments and related state.

    The module works without a card, but saving presets and loading samples, scripts or plug-ins requires a FAT32 or exFAT MicroSD card. Start with the supplied example presets to see complete routing patterns.

    Official manual: Getting started →

    Manual pages 16–19

    Panel controls and navigation

    Button 1 enters or exits menus. In menus, turn and press the left encoder to navigate; Button 2 goes back. Hold Button 3 for control help. Button 4 is a configurable shortcut, normally Mappings or Performance Page.

    In the overview, the left encoder or pot scrolls algorithms. Hold Button 4 and turn the left encoder to reorder; hold Button 4 and press the right encoder to toggle bypass. Press the left encoder or pot to enter the selected algorithm.

    In an algorithm, the left pot selects a parameter page, the centre pot or left encoder selects a parameter, and the right pot or encoder changes it. Pressing the right encoder usually restores the default. The right pot uses soft takeover; press it to jump directly to its physical position.

    Official manual: Navigation →

    Manual pages 20–22

    Inputs, outputs and USB

    The NT has 12 DC-coupled inputs. Jumpers select modular level (up to ±12 V, 101 kΩ) or line level (up to ±3.5 V / +10 dBu, 29 kΩ). Use 3.5 mm TS cables, not TRS.

    Six DC-coupled outputs are on the front; outputs 7–8 are available on rear header J5. Output range is up to ±11 V. The USB-C port provides class-compliant MIDI, Audio 2.0 and Video, but the NT is not a USB host and is not powered by USB.

    Official manual: Inputs, outputs and USB →

    Manual pages 41–43

    Presets and working memory

    Edits affect the live preset immediately but are not stored on the card until Save preset. The NT does not auto-save. Load parameters changes only values and requires the same algorithms in the same order, so audio does not stop for a full rebuild.

    Append, Insert and Prepend combine preset files with the current chain. A single algorithm or a range can be saved for reuse. An End of chain preset keeps a final section—such as venue EQ or limiting—in place while the main preset changes.

    Official manual: Presets →

    Manual pages 29–30

    Signal flow and busses

    Algorithms read and write numbered busses. Busses 1–12 correspond to module inputs, 13–20 to outputs 1–8, and the remaining 44 are internal aux busses. An algorithm’s output can Add to what is already on a bus or Replace it.

    Algorithms execute in slot order. A consumer normally needs to sit below the algorithm producing its signal. Feedback Receive/Send is the deliberate mechanism for routes that need to cross the normal top-to-bottom order.

    Official manual: Signal flow →

    Manual pages 72–427

    Algorithm index

    Sources and control: Clock, LFO, envelopes, sequencers, Chaos, Noise, MIDI Triggers, MIDI CC Generator and Virtual CVC. Pitch and synthesis: VCOs, Poly CV/FM/Wavetable/Multisample/Resonator, Dream Machine and macro oscillators.

    Audio processing: mixers, filters, EQ, dynamics, delays, reverbs, spectral processors, pitch/frequency shifters and granular/texture effects. Sampling and looping: Sample Players, Audio Recorder, Auto-sampler, Looper and Looper (MicroSD). Utilities: Attenuverter, Logic, Multi-Switch, Quantizer, Scope, Tuner and routing helpers.

    Each algorithm’s manual entry lists its specifications, UI, parameters, input/output busses and special behaviour. Search this wiki for a family, then use the full manual’s contents for the exact algorithm.

    Official manual: Algorithm reference →

    Manual pages 44–47

    CV, MIDI and I²C mappings

    Any parameter can have several mapping types at once, and one controller can drive several parameters. Mappings are stored in the preset.

    CV mappings add to the preset value unless set as a Gate. Sources can be the algorithm’s own inputs, the physical module inputs, or another algorithm’s outputs. The change is CV volts × Delta ÷ Volts. Unipolar clamps negative CV to 0 V.

    MIDI and I²C mappings directly set values. MIDI supports CC, momentary/toggle notes, pitch bend, channel pressure, 14-bit CC, relative CC and—when enabled—NRPN. Symmetric mode guarantees the controller midpoint maps to the parameter midpoint. Learn captures the next received control.

    Official manual: Mappings →

    Manual pages 35–37 and 48

    Performance Page

    The Performance Page is a preset-wide collection of chosen parameters, independent of MIDI mappings. Assign a Performance Page index from the parameter’s mapping setup. Items can be renamed, constrained to custom min/max values and reordered.

    The first four controls correspond to the four pots, and pages extend the available set. Knob Recorder algorithms can capture and replay gestures, optionally clock-synchronised. Firmware 1.18 makes a knob press reset its assigned parameter to default.

    Official manual: Performance Page →

    Manual pages 31–32 and 50

    CPU, sample rate and block size

    The overview reports audio CPU and overall CPU. Expert Sleepers recommends keeping total algorithm/audio CPU below about 90% for reliable operation. Overall load also includes display, MicroSD and background work, so it can sometimes be significantly higher. Overload can cause crackling, a slow UI and eventually muted algorithm processing.

    Engine sample rates are 32, 44.1, 48, 88.2 or 96 kHz. Higher sample rates and smaller blocks cost more CPU, while larger blocks increase latency. Sample-rate and block-size changes require Apply. USB may control sample rate if Allow USB rate change is enabled; changing that option requires rebooting.

    Official manual: Engine and CPU →

    Manual pages 13 and 50–51

    NTX-8CV, ES-5 and ESX

    CV (8×8): up to eight NTX-8CVs provide 64 time-interleaved CV outputs. Channels are individually enabled; enabling unused channels wastes some CPU. Audio 32-bit: one unit provides eight full-resolution channels. Audio 16-bit: two units provide 16 channels. Match the NTX sample rate to the NT for audio modes.

    NTX channels 1–44 carry aux 1–44, channels 45–56 carry inputs 1–12, and channels 57–64 carry outputs 1–8. In CV mode, NTX can share the link with an ES-5 and up to two ESX expanders, but shared mode halves NTX bandwidth. ES-5/ESX are otherwise addressed by compatible algorithms rather than ordinary output busses.

    Official manual: NTX-8CV settings →

    Manual pages 22–28 and 55–56

    MicroSD, samples and plug-ins

    Use FAT32 or exFAT. Presets are JSON. Key folders include presets, samples, wavetables, MIDI, recordings, programs/lua, programs/plug-ins, scl, kbm and MTS.

    Samples may be mono or stereo WAV at any sample rate, in 8/16/24-bit or 32-bit float. Filename tags define natural pitch, switch points, round robins and velocity layers. After reinserting a powered-on card, use Remount. Use Regenerate wavcache files for unexpected corrupt/unsupported WAV errors. USB disk mode suspends all other NT operation; eject the disk before rebooting.

    Official manual: MicroSD card →

    Manual pages 21 and 52–53

    MIDI, Program Change and I²C

    MIDI arrives over USB, the optional breakout or Select Bus, with configurable forwarding. Soft takeover can be Sudden, Gradual or Always on; relative CC mappings bypass it. NRPN support uses CC 99/98 for the number and CC 6/38 for the value.

    Program Change loads a preset whose filename contains #number; otherwise it indexes the alphabetically sorted files. I²C can control mappings, play notes and exchange commands through rear header J8. Exactly one or more devices on an I²C bus must provide pull-ups.

    Official manual: MIDI settings →

    Manual pages 49–55

    Useful global settings

    Display: contrast, flip, screensaver, USB Video support and CPU display rate. UI: help duration, Button 4 shortcut, encoder preference, pot threshold and adding new algorithms already bypassed. Startup: optionally load the last saved or loaded preset—remember this is not auto-save.

    MIDI: CC/SysEx view changes, CC feedback, Learn exclusivity, device ID, Program Change and forwarding. Globals: master tuning. Calibration: factory calibration can be restored; save calibration explicitly to flash after changes.

    Official manual: Settings →

    Manual pages 31–32 and 56–58

    Troubleshooting

    Clicks or overload: lower algorithm cost, reduce sample rate or increase block size. Card was removed: reinsert it and choose Remount. WAV reported corrupt: regenerate wavcache first. Stuck MIDI notes: Misc → MIDI → All notes off or All sound off.

    No MIDI control: use the MIDI monitor, then the Mappings monitor. Check channel, type, enabled state and soft takeover. No I²C response: use the I²C monitor, confirm address and ensure the bus has pull-ups. A fault screen preserves debugging information and lets you reboot.

    Official manual: Diagnostics →

    NT Pilot

    Connection and synchronization

    NT Pilot uses MIDI SysEx to discover the module and exchange live preset data. Leave the SysEx device ID at 0 for one NT; use distinct IDs for several modules. The Connected state means the NT answered an identity request, not merely that a MIDI port exists.

    Fast synchronization refreshes changing state more often. Parameter and routing edits alter working memory immediately; use Save preset when you want the result written to the MicroSD card.
